## Overview
The Library Management System (LMS) is a Java console application designed to manage library items, users, loans, returns, reservations, and operational reports.

The application provides a structured way to manage library resources while preventing invalid circulation operations and maintaining consistent domain states.

## Features

- Load/save data from files
- add, remove items to library
- Borrow, return system
- Reserve unavailable items.
- item search
- catalogue
- item sorting
- handle errors and user input




## Run
